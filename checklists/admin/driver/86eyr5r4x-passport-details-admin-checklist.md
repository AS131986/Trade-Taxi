## Подтверждённые уточнения

- Актуальные статусы админки: `Не загружено` и `Проверено {дата}`.
- Отчество необязательно для всех стран.
- ФИО РФ: кириллица, пробел, дефис. Иностранное ФИО: кириллица, латиница, пробел, дефис, апостроф.

- Другие неприменимые документы блокируются, но их файлы сохраняются; это не удаление постоянной прописки.

- [ ] **[HIGH]** Книжка с одним фото → ID-карта: сохранить без второй обязательной стороны нельзя.
- [ ] После добавления обеих сторон ID-карта успешно сохраняется.
- [ ] ID-карта → книжка: остаётся одно активное вложение `Основная страница`.
- [ ] Скрытая оборотная сторона не вызывает ошибку обязательности при сохранении книжки.
- [ ] **[HIGH]** При сохранении книжки оборотная сторона не сохраняется как второе активное вложение книжки.
- [ ] После сохранения книжки и повторного открытия отображается одна страница.
- [ ] Переключение формы не меняет выбранную страну.
- [ ] Переключение формы не очищает общие реквизиты паспорта.
- [ ] Переключение формы не отменяет правила валидации реквизитов.
- [ ] Быстрое переключение `Книжка → ID-карта → Книжка` не создаёт дублирующих вложений.
- [ ] Отмена редактирования после смены формы сохраняет прежнюю форму и вложения на сервере.
- [ ] Ошибка сохранения после смены формы не приводит к частичной потере сохранённых фото.
- [ ] Завершение загрузки после переключения формы не прикрепляет фото к неправильной стороне.

### Совместная смена страны и формы

- [ ] **[HIGH]** РФ с двумя фото → иностранная книжка: после подтверждённого сохранения остаётся одна основная страница.
- [ ] **[HIGH]** РФ с двумя фото → иностранная ID-карта: фото прописки не становится автоматически оборотной стороной ID-карты.
- [ ] Для новой ID-карты обязательность обеих сторон проверяется независимо от прежних двух фото РФ.
- [ ] Иностранная ID-карта → РФ: оборотная сторона ID-карты не становится автоматически фото прописки.
- [ ] Смена одной иностранной страны на другую в режиме книжки не создаёт второе активное вложение.
- [ ] Смена одной иностранной страны на другую в режиме ID-карты не позволяет обойти обязательность двух сторон.
- [ ] **[HIGH]** Последовательность `РФ → иностранная книжка → ID-карта → РФ` без сохранения не удаляет сохранённые данные и фото на сервере.
- [ ] После успешного сохранения итоговые страна, форма, поля и вложения соответствуют друг другу.

## Сохранение и ошибки

- [ ] **[HIGH]** Валидные данные с обязательными для выбранной формы фото успешно сохраняются.
- [ ] После повторного открытия значения совпадают с сохранёнными.
- [ ] При ошибке сохранения не отображается сообщение об успехе.
- [ ] При ошибке сохранения статус и дата не меняются как после успешного сохранения.
- [ ] После ошибки можно повторить сохранение без потери введённых данных.
- [ ] Повторное нажатие сохранения не создаёт дублирующих документов.
- [ ] **[HIGH]** Сохранение паспорта не изменяет данные другого водителя.
- [ ] Сохранение паспорта не перезаписывает другие документы водителя.
- [ ] При потере ответа повторная попытка не создаёт дублирующих операций и записей истории.
- [ ] После обновления страницы отображается фактическое сохранённое состояние.
- [ ] Ошибка загрузки одной стороны ID-карты не отображается как успешное сохранение всего документа.

## История изменений

Основание: [документация истории](../../../docs/admin/driver/history.md) и [существующий чек-лист](history-checklist.md). Новые записи не следует смешивать с изменением старых исторических записей; формат истории удаления требует уточнения.

- [ ] Одно сохранение нескольких полей создаёт одну строку истории.
- [ ] В истории отображаются корректные старые и новые значения.
- [ ] Для ранее пустого поля отображается `Пусто`.
- [ ] Старое значение отображается зачёркнутым.
- [ ] Добавление отчества отражается как переход от пустого значения к заполненному.
- [ ] Удаление отчества отражается как переход от заполненного значения к пустому.
- [ ] Кириллица, латиница и апостроф в разрешённых полях отображаются без искажения.
- [ ] Корректно отображаются автор и дата изменения.
- [ ] Первая загрузка фото отображается как `Загружено фото`.
- [ ] Замена фото отображается как `Фото заменено`.
- [ ] Для ID-карты ссылка изменения фото открывает именно изменённую сторону.
- [ ] Фото по ссылке истории открывается в браузере без принудительного скачивания.
- [ ] При редактировании полей текущего типа паспорта в новой записи не появляются посторонние поля другого типа.
- [ ] При изменении более четырёх полей работает `Показать все`.
- [ ] Отмена смены страны или формы не создаёт запись об изменении документа.
- [ ] Неуспешное сохранение не создаёт запись об успешно выполненном изменении.
- [ ] Фото истории недоступно без авторизации — `401`.
- [ ] Фото истории недоступно с токеном водителя — `403`.

## API и доступ

- [ ] **[HIGH]** Через API нельзя сохранить паспорт без обязательных полей.
- [ ] Через API можно сохранить паспорт без отчества.
- [ ] Через API можно удалить ранее заполненное отчество.
- [ ] API принимает кириллицу, пробел и дефис в ФИО паспорта РФ.
- [ ] **[HIGH]** API отклоняет латиницу в ФИО паспорта РФ.
- [ ] API отклоняет апостроф в ФИО паспорта РФ.
- [ ] API принимает кириллицу и латиницу в ФИО иностранного паспорта.
- [ ] API принимает пробел, дефис и апостроф в ФИО иностранного паспорта.
- [ ] Для всех стран API отклоняет цифры и остальные запрещённые символы в ФИО.
- [ ] API принимает кириллицу и латиницу в месте рождения иностранного паспорта.
- [ ] API принимает кириллицу и латиницу в поле `Кем выдан` иностранного паспорта.
- [ ] **[HIGH]** Через API нельзя сохранить книжку без основной страницы.
- [ ] **[HIGH]** Через API нельзя сохранить ID-карту без лицевой стороны.
- [ ] **[HIGH]** Через API нельзя сохранить ID-карту без оборотной стороны.
- [ ] Через API можно сохранить ID-карту с обеими сторонами и валидными реквизитами.
- [ ] API сохраняет форму паспорта и возвращает её при повторном чтении.
- [ ] API не принимает неизвестное значение формы паспорта.
- [ ] Лицевая и оборотная стороны возвращаются с правильной принадлежностью.
- [ ] Через API нельзя обойти ограничения формата остальных полей.
- [ ] Через API нельзя сохранить просроченный иностранный паспорт.
- [ ] Через API нельзя сохранить частично заполненную прописку без обязательных полей.
- [ ] Через API можно сохранить паспорт с полностью пустой пропиской.
- [ ] **[HIGH]** После смены страны API не сохраняет устаревшие значения неприменимых полей.
- [ ] **[HIGH]** Успешная смена страны и удаление регистрации выполняются согласованно, без частичного сохранения.
- [ ] Смена формы через API не оставляет лишние активные стороны у книжки.
- [ ] **[HIGH]** Пользователь без соответствующих прав не может читать или изменять паспорт другого водителя.
- [ ] Неуспешное сохранение не переводит незагруженный документ в статус `Проверено`.
- [ ] Текст паспортных полей не исполняется как HTML/JavaScript.

## Открытые вопросы и проверки после уточнения

Каждый пункт ниже — вопрос к Product/BA/Developer и соответствующая условная проверка, не утверждение о готовом поведении.

- [ ] Проверить допустимость смешения кириллицы и латиницы внутри одного текстового поля иностранного паспорта.
- [ ] Проверить точный формат и длину номера паспорта РФ. Предложение «6 цифр» не подтверждено и не фиксируется как требование.
- [ ] Проверить ограничения длины иностранных номеров.
- [ ] Проверить максимальные длины текстовых полей.
- [ ] Проверить допустимость срока действия, равного сегодняшней дате.
- [ ] Проверить обязательность фото прописки при полностью пустом блоке.
- [ ] Проверить формат `кода структуры` после уточнения его соответствия `Коду подразделения` из PDF. Необязательность поля подтверждена отдельно.
- [ ] Проверить допустимый алфавит букв в квартире и корпусе.
- [ ] Проверить допустимые форматы и максимальный размер фото. Ограничения чатов поддержки к паспортам не переносить.
- [ ] Проверить точный момент появления подтверждения удаления регистрации.
- [ ] Проверить состояние выбранной страны и несохранённых полей после `Отмена` и `×`.
- [ ] Проверить необходимость подтверждения удаления регистрации при наличии только фото.
- [ ] Проверить необходимость подтверждения удаления регистрации при наличии только полей.
- [ ] Проверить необходимость подтверждения при полностью пустой регистрации.
- [ ] Проверить обработку основного фото при смене страны: сохраняется прежнее или требуется новое.
- [ ] Проверить перенос основной страницы книжки в лицевую сторону ID-карты по согласованному правилу.
- [ ] Проверить судьбу оборотной стороны при переходе ID-карта → книжка: удаление, отвязка или сохранение до обратного переключения.
- [ ] Проверить необходимость подтверждения при удалении оборотной стороны через смену формы.
- [ ] Проверить значение формы по умолчанию для нового иностранного паспорта.
- [ ] Проверить сохранение или сброс формы при смене одной иностранной страны на другую.
- [ ] Проверить отображение смены формы и удаления вложений в истории по согласованному формату.
- [ ] Проверить отображение удалённых полей и вложений в прежних записях истории — отдельно от новой записи изменения.
- [ ] **[HIGH]** Проверить выпуск ЭПЛ при `Не загружено` и `Проверено {дата}` по согласованной матрице.
- [ ] **[HIGH]** Проверить выпуск ЭПЛ для ранее сохранённого паспорта, срок действия которого истёк позднее.
