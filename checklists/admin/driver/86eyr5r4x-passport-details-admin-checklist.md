## Подтверждённые уточнения

- Актуальные статусы админки: `Не загружено` и `Проверено {дата}`.
- Отчество необязательно для всех стран.
- ФИО РФ: кириллица, пробел, дефис. Иностранное ФИО: кириллица, латиница, пробел, дефис, апостроф.
- Другие текстовые поля иностранного паспорта принимают кириллицу и латиницу с собственным набором допустимых символов поля. Формат номера проверяется отдельно как реквизит.
- Без обязательного фото сохранение запрещено. Иностранная книжка требует одну основную страницу; ID-карта — лицевую и оборотную стороны.
- Пустая постоянная прописка допустима. Любое заполненное поле активирует обязательность даты регистрации, региона, пункта, улицы и дома. Квартира, корпус, отделение и код структуры необязательны.
- Просроченный иностранный паспорт сохранять нельзя.
- При переходе с РФ на иностранный паспорт данные и фото постоянной регистрации удаляются после подтверждённого успешного сохранения; скриншот содержит `Отмена`, `×`, `Удалить и сохранить`.
- Другие неприменимые документы блокируются, но их файлы сохраняются; это не удаление постоянной прописки.

### Запись выполнена, ответ потерян

Предусловие: факт успешной записи установлен повторным чтением/доступной диагностикой; ошибка транспорта сама по себе этого не доказывает. Название сообщения и механизм повторов не задаются без контракта.

- [ ] `PAS-217` **[HIGH]** После выполненной записи с потерянным ответом повторное чтение показывает новые сохранённые поля.
- [ ] `PAS-218` После выполненной записи с потерянным ответом список и деталка показывают статус/дату из фактического сохранённого состояния.

- [ ] `PAS-221` Повтор той же операции после потери ответа не создаёт вторую запись истории одного изменения.
- [ ] `PAS-222` Повтор той же операции после потери ответа не удаляет дополнительные вложения.
- [ ] `PAS-223` При неопределённом исходе таймаута последующее чтение и отображение согласуются с фактическим состоянием сервера; сам таймаут не используется как доказательство отката.

### Одновременное редактирование

Сценарии двух вкладок и двух администраторов определены в `PAS-C-25A`–`PAS-C-25D`. Их ожидаемый результат зависит от Q-PAS-25. Повторное нажатие кнопки одним пользователем не заменяет эти сценарии.
