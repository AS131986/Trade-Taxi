# Список документов водителя — Admin Web checklist

## Scope и источники

- Продукт: Trade Taxi; область: Admin Web; страница: карточка водителя → `Документы`.
- Покрытие: список, группы, реквизиты карточек, статусы, доступность, зависимости и регрессия списка.
- Деталка паспорта, поля, фото и переключение `Книжка` / `ID-карта`: [отдельный чек-лист #86eyr5r4x](86eyr5r4x-passport-details-admin-checklist.md).
- Основание: прежний чек-лист списка из Git и уточнения пользователя в чате Admin Web от 15.10.2026.
- Актуальные статусы админки: `Не загружено` и `Проверено {дата}`. Прежнее название `Обновлено` для админки заменено по уточнению пользователя.
- `[x]` — выполнено пользователем по сообщению о закрытии исходных блоков 1–6. Сборка и окружение не указаны. `[ ]` — выполнение не подтверждено; новые проверки не считаются автоматически пройденными. Это не отчёт об автоматизированном тестировании.

## Страница и карточка паспорта — закрыто пользователем

- [x] Вкладка `Документы` открывается без ошибок.
- [x] Отображаются группы `Основные`, `Иностранные`, `Дополнительные`.
- [x] Незаполненный паспорт имеет заголовок `Паспорт`.
- [x] У незаполненного паспорта вместо реквизитов отображается прочерк.
- [x] Незагруженный документ имеет статус `Не загружено`.
- [x] Заполненный паспорт имеет заголовок по выбранной стране.
- [x] Для паспорта РФ в списке отображаются серия и номер.
- [x] Для иностранного паспорта отображается только номер.
- [x] Загруженный документ имеет статус `Проверено {дата}`.
- [x] Статус и дата совпадают в списке и модалке.
- [x] После обновления страницы сохранённые данные отображаются корректно.
- [x] **[HIGH]** При переключении между водителями данные и фото не смешиваются.

## Доступность и сохранность других документов

- [ ] Для паспорта РФ группа `Иностранные` недоступна.
- [ ] Недоступные документы остаются видимыми в админке.
- [ ] Недоступные документы отображаются заблокированными.
- [ ] **[HIGH]** Ранее загруженные файлы заблокированных документов сохраняются.
- [ ] Файлы сохраняются после обновления страницы и повторного входа.
- [ ] После возврата к подходящей стране документ снова доступен с прежними файлами.
- [ ] **[HIGH]** При появлении ВНЖ/РВП у иностранного водителя документ `Патент` блокируется.
- [ ] При появлении ВНЖ/РВП блокируется `Чек об оплате патента`.
- [ ] При появлении ВНЖ/РВП блокируется `Амина`.
- [ ] При появлении ВНЖ/РВП блокируется `КИГ`.
- [ ] Заблокированный `Патент` остаётся видимым с сохранёнными файлами.
- [ ] Заблокированный `Чек об оплате патента` остаётся видимым с сохранёнными файлами.
- [ ] Заблокированная `Амина` остаётся видимой с сохранёнными файлами.
- [ ] Заблокированный `КИГ` остаётся видимым с сохранёнными файлами.
- [ ] Документы из других групп не блокируются без соответствующего бизнес-правила.
- [ ] После снятия основания блокировки доступность пересчитывается — для действий, поддерживаемых продуктом.
- [ ] Временная регистрация остаётся отдельной карточкой.
- [ ] Редактирование постоянной прописки не перезаписывает временную регистрацию.
- [ ] Переключение книжки и ID-карты не меняет файлы других документов.

Удаление постоянной прописки при смене паспорта РФ на иностранный с подтверждением — отдельный сценарий деталки. Его нельзя смешивать с блокировкой других документов, файлы которых сохраняются.

## Регрессия списка

- [ ] **[HIGH]** Изменение паспорта не меняет статусы несвязанных документов.
- [ ] **[HIGH]** Изменение паспорта не меняет даты несвязанных документов.
- [ ] Изменение паспорта не подменяет реквизиты в карточках других документов.
- [ ] После смены страны документы не дублируются внутри группы.
- [ ] После смены страны документы не дублируются между группами.
- [ ] После пересчёта доступности документы не переходят в неправильные группы.
- [ ] Порядок групп стабилен после повторного открытия страницы.
- [ ] Порядок документов стабилен после обновления страницы и повторного входа.
- [ ] Список корректно отображает одновременно незагруженные, загруженные и заблокированные документы.
- [ ] Ранее загруженный документ после блокировки не превращается в пустую строку или исчезнувшую карточку.
- [ ] Длинные реквизиты не перекрывают статус и дату в строке документа.
- [ ] Дата рядом с `Проверено` отображается в формате `ДД.ММ.ГГГГ`.
- [ ] Дата относится к правильному документу.
- [ ] Неполные данные документа не ломают список.
- [ ] Пустая или некорректная дата из ответа API не ломает отображение строки.
- [ ] После изменения данных водителя список показывает актуальную доступность документов.
- [ ] После пересчёта доступности сохраняется возможность открыть доступные документы.
- [ ] Документы из групп `Основные` и `Дополнительные` не блокируются из-за правила, относящегося только к группе `Иностранные`.
- [ ] После обновления страницы и повторного входа сохраняются актуальные состояния блокировки.

## Вопросы и условные проверки

- **Вопрос:** отображается ли дата у `Не загружено` в админке? Отсутствие даты явно описано в мобильном чек-листе; автоматически переносить это правило нельзя.
- **Вопрос:** ВНЖ/РВП блокирует только четыре перечисленных документа или всю группу `Иностранные`? Админский чек-лист из Git подтверждает четыре документа; мобильные материалы содержат обе формулировки.
- [ ] После уточнения проверить отображение даты у `Не загружено` в админке.
- [ ] После уточнения проверить область действия ВНЖ/РВП на группу `Иностранные`.

## Cross-platform / Integration impact

Это отдельная область, не результат тестирования Mobile в чате Admin Web.

- [ ] **[HIGH]** Недоступные документы остаются видимыми как disabled в админке, а в Mobile скрываются по подтверждённым правилам.
- [ ] Ранее заполненные `Амина` и `КИГ`, ставшие недоступными, остаются видимыми в админке и скрываются в Mobile.
- [ ] Реквизиты одного документа согласованно передаются между backend, админкой и Mobile.
- [ ] Изменение паспорта не меняет данные несвязанных документов в Mobile.
- [ ] После согласованного времени синхронизации Mobile получает актуальные изменения соответствующего документа.
- [ ] Названия статусов на каждой платформе соответствуют её требованиям: замена мобильного `Обновлено` на `Проверено` отдельно не подтверждена.
