# Список документов водителя — Admin Web checklist

## Scope и источники

- Продукт: Trade Taxi; область: Admin Web; страница: карточка водителя → `Документы`.
- Покрытие: список, группы, реквизиты карточек, статусы, доступность, зависимости и регрессия списка.
- Деталка паспорта, поля, фото и переключение `Книжка` / `ID-карта`: [отдельный чек-лист #86eyr5r4x](86eyr5r4x-passport-details-admin-checklist.md).
- Основание: прежний чек-лист списка из Git и уточнения пользователя в чате Admin Web от 15.10.2026.
- Актуальные статусы админки: `Не загружено` и `Проверено {дата}`. Прежнее название `Обновлено` для админки заменено по уточнению пользователя.
- `[x]` — выполнено пользователем по сообщению о закрытии исходных блоков 1–6. Сборка и окружение не указаны. `[ ]` — выполнение не подтверждено; новые проверки не считаются автоматически пройденными. Это не отчёт об автоматизированном тестировании.
- Матрица блокировок и реестр вопросов: [документация документов](../../../docs/admin/driver/documents.md). Постоянные ID `DOC-*` не перенумеровывать и не использовать повторно.
- `DOC-C-*` — условные сценарии со статусом `BLOCKED`, пока не получен ответ на связанный вопрос. Они не входят в счётчик открытых тестов. Для прогона фиксировать сборку, окружение, роль, состояние водителя, результат и ссылку на дефект.

## Страница и карточка паспорта — закрыто пользователем

- [x] `DOC-001` Вкладка `Документы` открывается без ошибок.
- [x] `DOC-002` Отображаются группы `Основные`, `Иностранные`, `Дополнительные`.
- [x] `DOC-003` Незаполненный паспорт имеет заголовок `Паспорт`.
- [x] `DOC-004` У незаполненного паспорта вместо реквизитов отображается прочерк.
- [x] `DOC-005` Незагруженный документ имеет статус `Не загружено`.
- [x] `DOC-006` Заполненный паспорт имеет заголовок по выбранной стране.
- [x] `DOC-007` Для паспорта РФ в списке отображаются серия и номер.
- [x] `DOC-008` Для иностранного паспорта отображается только номер.
- [x] `DOC-009` Загруженный документ имеет статус `Проверено {дата}`.
- [x] `DOC-010` Статус и дата совпадают в списке и модалке.
- [x] `DOC-011` После обновления страницы сохранённые данные отображаются корректно.
- [x] `DOC-012` **[HIGH]** При переключении между водителями данные и фото не смешиваются.

## Доступность и сохранность других документов

В сценариях с ВНЖ/РВП использовать подготовленное состояние, в котором основание блокировки активно. Спорные критерии появления/снятия основания — Q-DOC-04. Переходы выполнять с успешным сохранением; несохранённый выбор страны не считать изменением сохранённого списка.

- [ ] `DOC-013` Для паспорта РФ группа `Иностранные` недоступна.
- [ ] `DOC-014` Недоступные документы остаются видимыми в админке.
- [ ] `DOC-015` Недоступные документы отображаются заблокированными.
- [ ] `DOC-016` **[HIGH]** Ранее загруженные файлы заблокированных документов сохраняются.
- [ ] `DOC-017` Файлы сохраняются после обновления страницы и повторного входа.
- [ ] `DOC-018` После возврата к подходящей стране документ снова доступен, если остальные основания блокировки отсутствуют.
- [ ] `DOC-019` После снятия последнего основания блокировки доступны прежние сохранённые файлы документа.
- [ ] `DOC-020` **[HIGH]** При появлении ВНЖ/РВП у иностранного водителя документ `Патент` блокируется.
- [ ] `DOC-021` При появлении ВНЖ/РВП блокируется `Чек об оплате патента`.
- [ ] `DOC-022` При появлении ВНЖ/РВП блокируется `Амина`.
- [ ] `DOC-023` При появлении ВНЖ/РВП блокируется `КИГ`.
- [ ] `DOC-024` Заблокированный `Патент` остаётся видимым с сохранёнными файлами.
- [ ] `DOC-025` Заблокированный `Чек об оплате патента` остаётся видимым с сохранёнными файлами.
- [ ] `DOC-026` Заблокированная `Амина` остаётся видимой с сохранёнными файлами.
- [ ] `DOC-027` Заблокированный `КИГ` остаётся видимым с сохранёнными файлами.
- [ ] `DOC-028` Документы из других групп не блокируются без соответствующего бизнес-правила.
- [ ] `DOC-029` **[HIGH]** Иностранный паспорт с активным основанием ВНЖ/РВП → РФ → иностранный: патент остаётся заблокированным, пока основание ВНЖ/РВП действует.
- [ ] `DOC-030` В той же последовательности `Чек об оплате патента` остаётся заблокированным.
- [ ] `DOC-031` В той же последовательности `Амина` остаётся заблокированной.
- [ ] `DOC-032` В той же последовательности `КИГ` остаётся заблокированным.
- [ ] `DOC-033` Пересечение оснований РФ и ВНЖ/РВП не удаляет ранее загруженные файлы четырёх документов; каждое вложение проверяется отдельно.
- [ ] `DOC-034` Отмена смены страны без сохранения не меняет сохранённую доступность списка после повторного открытия.
- [ ] `DOC-035` Явный отказ сервера сохранить страну без записи не меняет сохранённую доступность списка.
- [ ] `DOC-036` Временная регистрация остаётся отдельной карточкой.
- [ ] `DOC-037` Редактирование постоянной прописки не перезаписывает временную регистрацию.
- [ ] `DOC-038` Переключение книжки и ID-карты не меняет файлы других документов.

Удаление постоянной прописки при смене паспорта РФ на иностранный с подтверждением — отдельный сценарий деталки. Его нельзя смешивать с блокировкой других документов, файлы которых сохраняются.

## Регрессия списка

- [ ] `DOC-039` **[HIGH]** Изменение паспорта не меняет статусы несвязанных документов.
- [ ] `DOC-040` **[HIGH]** Изменение паспорта не меняет даты несвязанных документов.
- [ ] `DOC-041` Изменение паспорта не подменяет реквизиты в карточках других документов.
- [ ] `DOC-042` После смены страны документы не дублируются внутри группы.
- [ ] `DOC-043` После смены страны документы не дублируются между группами.
- [ ] `DOC-044` После пересчёта доступности документы не переходят в неправильные группы.
- [ ] `DOC-045` Порядок групп стабилен после повторного открытия страницы.
- [ ] `DOC-046` Порядок документов стабилен после обновления страницы и повторного входа.
- [ ] `DOC-047` Список корректно отображает одновременно незагруженные, загруженные и заблокированные документы.
- [ ] `DOC-048` Ранее загруженный документ после блокировки не превращается в пустую строку или исчезнувшую карточку.
- [ ] `DOC-049` Длинные реквизиты не перекрывают статус и дату в строке документа.
- [ ] `DOC-050` Дата рядом с `Проверено` отображается в формате `ДД.ММ.ГГГГ`.
- [ ] `DOC-051` Дата относится к правильному документу.
- [ ] `DOC-052` У одного документа отсутствуют реквизиты в ответе API — остальные карточки остаются видимыми с собственными реквизитами.
- [ ] `DOC-053` У иностранного паспорта нет серии в ответе API — карточка отображает его номер без подстановки серии другого документа.
- [ ] `DOC-054` Дата одного документа равна `null` — строка документа остаётся видимой, остальные строки доступны.
- [ ] `DOC-055` Дата одного документа отсутствует в ответе API — остальные документы сохраняют собственные даты.
- [ ] `DOC-056` Дата одного документа содержит невалидное значение — список остаётся доступным для открытия остальных документов.
- [ ] `DOC-057` После изменения данных водителя список показывает актуальную доступность документов.
- [ ] `DOC-058` После пересчёта доступности сохраняется возможность открыть доступные документы.
- [ ] `DOC-059` Документы из групп `Основные` и `Дополнительные` не блокируются из-за правила, относящегося только к группе `Иностранные`.
- [ ] `DOC-060` После обновления страницы и повторного входа сохраняются актуальные состояния блокировки.

Точный текст заглушки для неполных данных проверяется после Q-DOC-07. Проверки устойчивости выше не назначают конкретную заглушку без требования.

## Загрузка и согласованность сохранённого состояния

- [ ] `DOC-061` **[HIGH]** Ошибка загрузки списка не отображается как подтверждённое отсутствие всех документов водителя.
- [ ] `DOC-062` После повторной загрузки вслед за ошибкой отображаются документы выбранного водителя.
- [ ] `DOC-063` Поздний ответ списка для водителя A после перехода к B не подменяет документы B.
- [ ] `DOC-064` **[HIGH]** Сервер сохранил паспорт, ответ потерян — после обновления списка реквизиты соответствуют фактической сохранённой версии.
- [ ] `DOC-065` При таком сохранении статус карточки совпадает со статусом повторно прочитанного документа.
- [ ] `DOC-066` При таком сохранении дата карточки совпадает с датой повторно прочитанного документа.
- [ ] `DOC-067` Явный отказ сервера без записи оставляет прежний сохранённый статус паспорта.
- [ ] `DOC-068` Явный отказ сервера без записи оставляет прежнюю сохранённую дату паспорта.

## Cross-platform / Integration impact

Это отдельная область, не результат тестирования Mobile в чате Admin Web.

- [ ] `DOC-069` **[HIGH]** Недоступные документы остаются видимыми как disabled в админке, а в Mobile скрываются по подтверждённым правилам.
- [ ] `DOC-070` Ранее заполненные `Амина` и `КИГ`, ставшие недоступными, остаются видимыми в админке и скрываются в Mobile.
- [ ] `DOC-071` Реквизиты одного документа согласованно передаются между backend, админкой и Mobile.
- [ ] `DOC-072` Изменение паспорта не меняет данные несвязанных документов в Mobile.

Срок синхронизации и возможное изменение названий статусов Mobile проверяются в `DOC-C-06`. Замена мобильного `Обновлено` на `Проверено` отдельно не подтверждена.
