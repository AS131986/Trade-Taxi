# Trade Taxi QA Workspace

One working directory for Trade Taxi QA across Admin Web, Mobile, and API/backend.

Recommended Chatbox chats:
- `Trade Taxi — Admin Web QA`
- `Trade Taxi — Mobile QA`
- optional `Trade Taxi — General QA`

All chats can use this same working directory. The active chat should state its scope explicitly.

## Suggested Admin Web chat scope
Project: Trade Taxi
Area: Admin Panel
Platform: Web
Work primarily with Admin Web. Do not include Mobile or other product areas in the main checklist unless directly in scope. If they may be affected, report them separately under `Cross-platform / Integration impact`. Use `docs/admin/`, `checklists/admin/`, and `regression/ADMIN-REGRESSION.md` for Admin-specific persisted information. Follow `QA-INSTRUCTIONS.md`. Modify files only when explicitly asked.

## Suggested Mobile chat scope
Project: Trade Taxi
Area: Mobile
Platform: Mobile
Work primarily with the mobile product. Do not include Admin Web in the main checklist unless directly in scope. If it may be affected, report it separately under `Cross-platform / Integration impact`. Use `docs/mobile/`, `checklists/mobile/`, and `regression/MOBILE-REGRESSION.md` for Mobile-specific persisted information. Follow `QA-INSTRUCTIONS.md`. Modify files only when explicitly asked.
