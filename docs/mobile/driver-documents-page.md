# Driver documents page — Mobile documentation

## Scope
- Product: Trade Taxi
- Area: Driver App
- Platform: Mobile
- Page: `Документы`
- This document describes confirmed functional behavior of the document list in Mobile only.

## Purpose of the page
Экран `Документы` в мобильном приложении показывает список документов водителя, их текущий статус и доступность в зависимости от бизнес-правил.

## Page structure
Экран состоит из групп документов:
- `Основные`
- `Иностранные`
- `Дополнительные`

Состав документов в Mobile должен быть тем же, что и в Web.

Каждый документ отображается отдельной строкой/карточкой.

В нижней части экрана отображается CTA `Обновить документы`.

## Document card content
Строка/карточка документа содержит:
- название документа;
- вторичное значение под названием документа;
- статус документа.

Логика отображения вторичного значения должна быть такой же, как в Web.

Если документ загружен, в статусе также отображается дата обновления.

## Document statuses
Для документа в списке подтверждены 2 базовых статуса:
- `Не загружено`
- `Обновлено`

### `Не загружено`
Статус `Не загружено` означает, что документ не загружен.

### `Обновлено`
Статус `Обновлено` означает, что документ загружен или ранее был обновлён.
Рядом со статусом отображается дата обновления в формате `ДД.ММ.ГГГГ`.

## Hidden behavior in Mobile
Если документ или группа документов недоступны по бизнес-правилу:
- они скрываются из списка;
- они отсутствуют на экране;
- они не отображаются в состоянии `disabled`.

Если документ был загружен ранее, а затем стал недоступен по бизнес-правилу:
- документ не должен отображаться в Mobile;
- документ не должен оставаться видимым в состоянии `disabled`.

## Business rules

### Rule 1. Не `Паспорт РФ` и без `ВНЖ/РВП`
Если у водителя не `Паспорт РФ` и нет `ВНЖ/РВП`, документы из группы `Иностранные` должны отображаться в Mobile.

Expected behavior in Mobile:
- группа `Иностранные` отображается в списке;
- документы из группы `Иностранные` доступны для отображения в обычных состояниях;
- документы из группы `Иностранные` могут отображаться со статусами `Не загружено` или `Обновлено`.

### Rule 2. `Паспорт РФ`
Если у водителя есть `Паспорт РФ`, документы из группы `Иностранные` в Mobile должны быть скрыты.

Expected behavior in Mobile:
- группа `Иностранные` не отображается в списке, если все её документы недоступны;
- недоступные документы из группы `Иностранные` отсутствуют в списке;
- недоступные документы из группы `Иностранные` не отображаются как `disabled`;
- документы из групп `Основные` и `Дополнительные` не скрываются без отдельного правила.

### Rule 3. Не `Паспорт РФ` + `ВНЖ/РВП`
Если у водителя не `Паспорт РФ` и есть `ВНЖ/РВП`, документы из группы `Иностранные` в Mobile должны быть скрыты.

Expected behavior in Mobile:
- группа `Иностранные` не отображается в списке, если её документы недоступны по этому правилу;
- документы из группы `Иностранные` отсутствуют в списке;
- документы из группы `Иностранные` не отображаются как `disabled`.

### Rule 4. `ВНЖ/РВП`
Если водитель иностранец и у него есть `ВНЖ/РВП`, документы:
- `Патент`
- `Чек об оплате патента`
- `Амина`
- `КИГ`

не должны отображаться в Mobile, если они недоступны по правилу.

Expected behavior in Mobile:
- перечисленные документы отсутствуют в списке;
- перечисленные документы не отображаются как `disabled`;
- если `Амина` или `КИГ` были загружены ранее, в Mobile они всё равно не отображаются;
- ранее заполненные `Амина` и `КИГ`, ставшие `disabled`, остаются видимыми только в Admin Panel.
- если `ВНЖ/РВП` делает недоступными документы группы `Иностранные`, эта группа не отображается в Mobile.

### Rule 5. Статусы документов группы `Иностранные`
Если группа `Иностранные` отображается в Mobile, документы внутри неё должны использовать те же базовые статусы, что и остальные документы списка:
- `Не загружено`
- `Обновлено`

Если группа `Иностранные` скрыта по бизнес-правилу, её документы не должны отображаться ни в каком состоянии.

## Difference between Admin Panel and Mobile
Один и тот же бизнес-принцип отображается по-разному:

### Admin Panel
Недоступный элемент:
- виден в списке;
- отображается как `disabled`.

### Mobile application
Недоступный элемент:
- скрыт;
- отсутствует в списке.

Для `Амина` и `КИГ` это правило также действует: если они стали `disabled`, в Mobile они не показываются даже при ранее заполненных данных.

## Notes for QA
При проверке экрана `Документы` в Mobile важно отдельно проверять:
- корректность структуры списка;
- корректность статусов `Не загружено` / `Обновлено`;
- корректность даты обновления в формате `ДД.ММ.ГГГГ`;
- совпадение состава документов с Web;
- совпадение логики вторичного значения с Web;
- скрытие недоступных документов вместо disabled-состояния;
- отображение группы `Иностранные` в сценарии: не `Паспорт РФ` и без `ВНЖ/РВП`;
- скрытие группы `Иностранные` в сценариях: `Паспорт РФ` и не `Паспорт РФ` + `ВНЖ/РВП`;
- отсутствие отображения ранее заполненных `Амина` и `КИГ`, если они стали `disabled`;
- обновление даты после действия `Обновить документы` без проверки полного flow загрузки/редактирования.

## Confirmed limitations of this document
Этот документ описывает только подтверждённое поведение экрана списка документов в Mobile.

Вне scope этого документа:
- логика загрузки документов;
- логика редактирования документов;
- логика удаления документов;
- детальное описание API;
- детальное описание поведения Admin Panel.
