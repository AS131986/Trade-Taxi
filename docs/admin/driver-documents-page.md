# Driver documents page — Admin Panel documentation

## Scope
- Product: Trade Taxi
- Area: Admin Panel
- Platform: Web
- Page: Driver card → `Документы`
- This document describes confirmed behavior of the document list in Admin Panel only.

## Purpose of the page
Вкладка `Документы` в карточке водителя показывает список документов, их статус и доступность по бизнес-правилам.

## Page structure
Страница состоит из групп:
- `Основные`
- `Иностранные`
- `Дополнительные`

Каждый документ отображается отдельной карточкой.

## Document card content
Карточка документа содержит:
- название документа;
- вторичное значение под названием документа;
- статус документа.

Если документ загружен, рядом со статусом отображается дата обновления.

## Document statuses
Подтверждены 2 базовых статуса:
- `Не загружено`
- `Обновлено`

### `Не загружено`
Статус `Не загружено` означает, что документ не загружен.

### `Обновлено`
Статус `Обновлено` означает, что документ загружен или обновлён.
Рядом со статусом отображается дата обновления.

## Disabled behavior in Admin Panel
Если документ или группа документов недоступны по бизнес-правилу:
- они не скрываются из списка;
- они остаются видимыми;
- они отображаются как `disabled`.

Если документ был загружен ранее, а затем стал недоступен:
- он не удаляется из списка;
- он остаётся видимым;
- он отображается как `disabled`.

## Business rules

### Rule 1. `Паспорт РФ`
Если у водителя есть `Паспорт РФ`, группа `Иностранные` в Admin Panel должна быть `disabled`.

Ожидаемое поведение:
- группа `Иностранные` остаётся видимой;
- группа `Иностранные` отображается как недоступная;
- документы внутри группы `Иностранные` не скрываются;
- ранее загруженные документы в этой группе остаются видимыми и отображаются как `disabled`.

### Rule 2. `ВНЖ/РВП`
Если водитель иностранец и у него есть `ВНЖ/РВП`, документы:
- `Патент`
- `Чек об оплате патента`
- `Амина`
- `КИГ`

должны быть `disabled` в Admin Panel.

Ожидаемое поведение:
- документы остаются видимыми в списке;
- документы отображаются как недоступные;
- если какой-то из этих документов был загружен ранее, он не удаляется, а остаётся видимым как `disabled`.

## Difference between Admin Panel and Mobile
Один и тот же бизнес-принцип отображается по-разному:

### Admin Panel
Недоступный элемент:
- виден в списке;
- отображается как `disabled`.

### Mobile application
Недоступный элемент:
- скрыт;
- отсутствует в списке.

## Notes for QA
При проверке страницы `Документы` в Admin Panel важно отдельно проверять:
- структуру списка;
- статусы `Не загружено` / `Обновлено`;
- disabled-состояние;
- сохранение ранее загруженных документов после перехода в недоступное состояние;
- отсутствие скрытия недоступных документов в Admin Panel;
- отличие поведения Admin Panel и Mobile в части отображения недоступных документов.

## Confirmed limitations of this document
Этот документ описывает только подтверждённое поведение страницы списка документов в Admin Panel.

Вне scope этого документа:
- логика загрузки документов;
- логика редактирования документов;
- логика удаления документов;
- детальное описание API;
- детальное описание Mobile UI.
