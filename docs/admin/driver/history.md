# Вкладка `История` — Admin Panel documentation

## Scope
- Продукт: Trade Taxi
- Область: Admin Panel
- Платформа: Web
- Страница: карточка водителя → `История`
- Scope: история редактирования документов, зафиксированная в Admin Panel после сохранения

## Purpose of the page
Вкладка `История` показывает историю изменений документов водителя после сохранения в Admin Panel.

## Page location
Вкладка `История` находится в карточке водителя как последняя вкладка после `Тех. осмотр`.

## Empty state
Если по водителю ещё не было ни одного изменения, показывается заглушка:
- иконка-иллюстрация;
- заголовок `История пока пуста`;
- подзаголовок `Изменения документов появятся здесь после первого сохранения`.

## List state
После появления хотя бы одного изменения на странице отображаются:
- панель фильтров;
- таблица записей истории.

## Filters
На странице доступны фильтры:
- поиск по автору изменений;
- выпадающий список по документу.

### Search
- Поиск работает по колонке `Автор изменений`.
- Поддерживается ручной ввод и вставка.
- Ограничение ввода — 100 символов.

### Document filter
- По умолчанию ничего не выбрано.
- Плейсхолдер фильтра — `Документ`.
- Фильтр — single select.
- Доступные значения:
  - `Паспорт`
  - `Права`
  - `Временная регистрация`
  - `ВНЖ`
  - `КИГ`
  - `Амина`
  - `Селфи`
  - `ИНН`
  - `СНИЛС`

## Table
### Default sorting
По умолчанию записи отсортированы по дате изменения, новые сверху.

### Columns
- `Дата изменения` — дата в первой строке, время во второй строке серым.
- `Автор изменений` — ФИО в первой строке, роль во второй строке серым мелким текстом.
- `Документ` — тип сущности, к которой относится изменение.
- `Изменения` — список изменённых полей.


## Changes cell behavior
- Формат изменения поля: `Название поля: старое значение → новое значение`.
- Старое значение отображается зачёркнутым.
- Если старое значение было пустым, показывается `Пусто` зачёркнутым.
- Если изменено несколько полей в рамках одного сохранения, они показываются построчно в одной ячейке.
- Если изменено более 4 полей, показываются первые 4, затем кнопка `Показать все`.
- По клику `Показать все` раскрывается полный список изменений внутри той же ячейки.
- После раскрытия кнопка `Показать все` скрывается.
- Одно сохранение формы = одна строка в истории.
- Не создаётся отдельная строка на каждое поле.

## File changes
- При загрузке файла в истории показывается `Загружено фото`.
- При замене фото в истории показывается `Фото заменено`.
- Слово `фото` является ссылкой и открывает файл по клику.

## Backend / access notes
- История начинается с новых сохранений в админке.
- Старые данные, приложение, импорт, Яндекс, проверка ИНН и смена статуса не входят в scope этой вкладки.
- Фото закрыты.
- Доступ к файлу истории есть только у сотрудника по token/cookie админки.
- Без входа возвращается `401`.
- С токеном водителя возвращается `403`.

## Confirmed limitations of this document
Этот документ описывает только подтверждённое поведение вкладки `История` в Admin Panel.

Вне scope этого документа:
- история неадминских изменений;
- старые данные до запуска истории;
- изменения из приложения;
- импорт;
- Яндекс;
- проверка ИНН;
- смена статуса.
