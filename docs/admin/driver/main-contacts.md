# Вкладка `Основное` → блок `Контакты`

Этот документ хранит подтверждённое поведение блока `Контакты` в Admin Panel.

## Scope
- Продукт: Trade Taxi
- Область: Admin Panel
- Платформа: Web
- Страница: карточка водителя → `Основное`
- Блок: `Контакты`

## Подтверждённое поведение
- У водителя может быть несколько контактов.
- Типы контактов: `Телефон` и `Email`.
- Для добавления и редактирования используется одна и та же модалка.
- Основной контакт удалять нельзя.
- Дополнительный контакт удалять можно.
- Основной контакт у водителя может быть только один.
- Email может быть только с ролью `Дополнительный`.
- Для основного контакта смена роли на `Дополнительный` запрещена.
- Тип контакта можно менять при редактировании, если контакт не основной.
- Номер основного контакта можно менять, при этом роль должна оставаться `Основной`.
- После смены основного номера старый номер должен перестать подходить для входа водителя.
- После смены номера он должен обновляться в шапке страницы и во вкладке `Приложение`.
- Есть проверка на дубли по телефонам и email.
- Примечание необязательное, максимум 500 символов.
