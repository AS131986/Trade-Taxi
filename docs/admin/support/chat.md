# Поддержка — Admin Panel documentation

## Scope
- Продукт: Trade Taxi
- Область: Admin Panel
- Платформа: Web
- Страница: `Поддержка`
- Scope: список обращений, чат, ответ, копирование и фильтры

## Overview
Страница `Поддержка` в Admin Panel используется для работы с обращениями водителей и менеджеров.

## List of chats
- В списке чатов пока не выводятся бейджи `Новое` и `Нет ответственного`.
- Отображается список обращений с превью последнего сообщения.
- Выбранный чат визуально активен.

## Chat header
- В шапке чата отображается ФИО собеседника.
- Отображаются телефон и номер/идентификатор.
- Справа показывается кнопка действия `Регистрация`.
- Отображается имя менеджера и название его отдела.
- Пока вместо названия отдела отображаем `Поддержка`.

## Message actions
### Context menu
- По long press на сообщении открывается контекстное меню.
- По right click на сообщении открывается контекстное меню.
- В меню доступны действия `Ответить` и `Скопировать`.

### Reply
- После выбора `Ответить` над полем ввода появляется превью цитируемого сообщения.
- В превью показываются имя, текст сообщения и кнопка `×`.
- Если текст длинный, он сокращается многоточием.
- После отправки сообщения-ответа показываются имя автора и цитата исходного сообщения.
- Если цитируется фото или файл, показывается миниатюра и подпись `Фото` или `Файл`.
- По данным API для цитаты имя автора зависит от типа отправителя: менеджер — имя, водитель — ФИО, bot — `null` или системное значение.

### Copy
- При выборе `Скопировать` текст копируется в буфер обмена.
- Меню закрывается.
- Показывается тост `Текст скопирован` на 2 секунды.

## Filters
- На странице есть кнопка `Фильтры`.
- Открывается экран фильтров.
- Экран фильтров можно закрыть кнопкой `×` или тапом вне панели.
- Доступен фильтр `Статус водителя` с множественным выбором.
- Доступен фильтр `Непрочитанные сообщения` с переключателем `Есть / Нет`.
- По умолчанию выбран `Нет`.
- После применения фильтров появляется кнопка `Сбросить`.
- `Сбросить` возвращает список к исходному состоянию.
- `Применить` закрывает экран фильтров и обновляет список.

## Notes
- Сейчас в списке чатов не выводим `Новое` и `Нет ответственного`.
- Мобильная версия поддерживает ту же логику, даже если визуально отличается.
